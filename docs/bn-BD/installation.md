## প্যাকেজ ইনস্টল করুন

Arch Linux-এ ARGVUS রিপোজিটোরি কনফিগার করা থাকা অবস্থায়, একবার argvus-ai সেখানে প্রকাশ করা হলে:

```sh
sudo pacman -S argvus-ai
```

একটি অবপ্রকাশিত লোকাল বিল্ডের জন্য, `argvus-ai` সোর্স রেপোসিটরিতে `make validate` এবং `make build` চালান, তারপর `argvus-ai` থেকে ফলস্বরূপ `.pkg.tar.zst`  `build/dist/` `sudo pacman -U /path/to/package.pkg.tar.zst` দিয়ে ইনস্টল করুন। Pacman-কে তার ডিপেন্ডেন্সিগুলি সমাধান করতে সক্ষম হতে হবে, যার মধ্যে প্রধান `argvus` প্যাকেজও রয়েছে।

প্যাকেজের জন্য `argvus`, `rofi`, `jq`, `mise`, `opencode` এবং `openai-codex`; Arch `/bin/sh` `bash` এর মাধ্যমে প্রদান করে। OpenCode `opencode` হিসাবে চলে, এবং `openai-codex` প্যাকেজ `codex` প্রদান করে।

## ডেস্কটপ ইন্টিগ্রেশনআপডেট করা `argvus-hyprland` এবং `argvus-taskbar` প্যাকেজগুলি ব্যবহার করুন। Hyprland `argvus-ai` দ্বারা সরবরাহিত ঐচ্ছিক Lua মডিউল লোড করে। ইন্টিগ্রেশনের Pacman হুক ইনস্টলেশন বা অপসারণের পর স্ট্যান্ডার্ড সিস্টেম কনফিগারেশন রিফ্রেশ করে। একটি কাস্টম root কনফিগারেশন বা নিষ্ক্রিয় autoreload একটি স্পষ্ট রিলোড প্রয়োজন করতে পারে। বিদ্যমান পার্সোনাল শর্টকাট ওভাররাইডগুলি প্রাধান্য বজায় রাখে।

আপডেট করা `argvus-appearance` প্রজেক্টর টাস্কবার মডিউল সংরক্ষণ করে এবং **Control Center > Appearance > Taskbar > Icons > Optional modules > AI Agents**-কে সম্মান করে। অপশনটি ডিফল্টভাবে সক্রিয় থাকে; পরিবর্তনের পর **Apply** ক্লিক করুন। এটি সক্রিয় করলে এজেন্ট ইনস্টল হয় না।

## ক্লড কোড প্রথম ব্যবহারেই

Rofi সিলেক্টর বা অ্যাপ্লিকেশন লঞ্চার থেকে Claude Code নির্বাচন করুন। ARGVUS টার্মিনাল খুলবে এবং যদি কোনো ইনস্টল করা সংস্করণ না পাওয়া যায় তবে এটি `mise install claude` আপনার সাধারণ ব্যবহারকারীর হিসেবে চালায়। প্রথম ইনস্টলেশনের জন্য নেটওয়ার্ক অ্যাক্সেস প্রয়োজন। র‍্যাপারটি ইনস্টল করা এক্সিকিউটেবলটি সমাধান করে এবং চালু করা প্রক্রিয়ার PATH-এ তার ডিরেক্টরি যোগ করে; এটি শেল স্টার্টআপ ফাইলগুলি সম্পাদনা করে না বা রুট হিসেবে ইনস্টল করে না। পরে চালনা করলে ইনস্টলেশনটি পুনঃব্যবহার করা হয়।

## সরান

```sh
sudo pacman -R argvus-ai
```

প্যাকেজ-স্বত্বাধীন Lua মডিউল এবং ডেস্কটপ এন্ট্রিগুলি সরানো হয়েছে, এবং টাস্কবার মডিউলটি লুকিয়ে যায় যখন তার হেল্পার অনুপস্থিত থাকে। স্ট্যান্ডার্ড Hyprland কনফিগারেশনটি বাইন্ড সরানোর জন্য স্বয়ংক্রিয়ভাবে পুনরায় লোড হয়। ব্যবহারকারীর স্বত্বাধীন mise টুলস, এজেন্ট সেটিংস এবং ক্রেডেনশিয়ালগুলি সংরক্ষণ করা হয়। Pacman এই কমান্ড দিয়ে স্বয়ংক্রিয়ভাবে এজেন্ট নির্ভরতা সরায় না।

ARGVUS AI প্যাকেজ প্যাকেজ-ইনস্টল সময়ে বাহ্যিক এজেন্ট ইনস্টল করে না। Hermes, Cursor CLI এবং Kimi প্রথম লঞ্চে ইনস্টল করুন; তাদের ব্যবহারকারীর ডেটা প্যাকেজের বাইরে থাকে। অপসারণের নির্দেশাবলীর জন্য ব্যবহার নির্দেশিকা দেখুন।

Arch Extra-এর `gemini-cli` প্যাকেজটি `argvus-ai`-এর নির্ভরতা হিসেবে ইনস্টল হয়; npm দিয়ে আলাদা ইনস্টল দরকার নেই।
