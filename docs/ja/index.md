title: AIエージェント
description: ARGVUSデスクトップからプログラミングエージェントを開きます。
---
`argvus-ai` は **OpenCode**、**OpenAI Codex**、**Claude Code** 向けのオプションのデスクトップ統合です。共有 Rofi セレクター、アプリケーションランチャーのエントリ、タスクバーのユーティリティグループにロボットアイコンを提供します。エージェントは新しい ARGVUS ターミナルウィンドウで実行され、呼び出し元の作業ディレクトリを保持します。

**SUPER + A** を押すか、タスクバーのマイクとオーディオコントロールの隣にある **nf-md-robot** をクリックしてセレクターを開きます。アプリケーションランチャーで個別のエージェントを選択することもできます。

OpenCode および Codex はパッケージ依存関係としてインストールされます。Claude Code は、ユーザーとして mise で、最初に選択したときのみインストールされます。パッケージのインストール、セレクターの開閉、状況確認では Claude はダウンロードされません。パッケージはアカウント、API キー、サブスクリプションを設定しません。選択したエージェントの認証プロンプトに従ってください。

[Installation](/docs/argvus-ai/installation/) および [使用法とトラブルシューティング](/docs/argvus-ai/usage/) を参照してください。

## 言語

`ai` カタログは、10 の ARGVUS 言語すべてで提供されており、共有の `argvus i18n` 選択肢と英語フォールバックを使用します。翻訳は、ユーザー設定を書き込むことなくデータとしてインストールされます。
