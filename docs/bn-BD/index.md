`argvus-ai` হল **OpenCode**, **OpenAI Codex** এবং **Claude Code**-এর জন্য একটি ঐচ্ছিক ডেস্কটপ ইন্টিগ্রেশন। এটি একটি ভাগ করা Rofi নির্বাচক, অ্যাপ্লিকেশন লঞ্চার এন্ট্রি এবং টাস্কবার ইউটিলিটি গ্রুপে রোবট আইকন প্রদান করে। এজেন্টরা একটি নতুন ARGVUS টার্মিনাল উইন্ডোতে চলে এবং কলারের কার্যকারী ডিরেক্টরি ধরে রাখে।

**SUPER + A** দিয়ে নির্বাচক খুলুন বা মাইক্রোফোন এবং অডিও নিয়ন্ত্রণের পাশে টাস্কবারে **nf-md-robot**-এ ক্লিক করুন। এছাড়াও আপনি অ্যাপ্লিকেশন লঞ্চারে একটি পৃথক এজেন্ট নির্বাচন করতে পারেন।

ওপেনকোড এবং কোডেক্স প্যাকেজ নির্ভরতা হিসাবে ইনস্টল করা হয়। ক্লাউড কোড আপনার ব্যবহারকারী হিসাবে mise দিয়ে ইনস্টল করা হয়, শুধুমাত্র আপনি যখন এটি প্রথম নির্বাচন করেন। প্যাকেজ ইনস্টল করা, নির্বাচক খোলা/বাতিল করা বা স্থিতি পরীক্ষা করা কখনই ক্লাউড ডাউনলোড করে না। প্যাকেজ অ্যাকাউন্ট, API কী বা সদস্যতা কনফিগার করে না; নির্বাচিত এজেন্টের প্রমাণীকরণ প্রম্পট অনুসরণ করুন।

পড়ুন [ইনস্টলেশন](/docs/argvus-ai/installation/) এবং [ব্যবহার এবং সমস্যা সমাধান](/docs/argvus-ai/usage/)।

## ভাষা

`ai` ক্যাটালগটি দশটি ARGVUS ভাষায় প্রদান করা হয়েছে এবং শেয়ার করা `argvus i18n` নির্বাচন এবং ইংরেজি ফলব্যাক ব্যবহার করে। অনুবাদগুলি ব্যবহারকারীর কনফিগারেশন না লিখে ডেটা হিসাবে ইনস্টল করা হয়।

## Agent coverage

ইন্টিগ্রেশন প্যাকেজ-প্রদত্ত OpenCode, Codex এবং Qwen কোড সমর্থন করে; Mise মাধ্যমে ক্লদ কোড; আলাদাভাবে ইনস্টল করার সময় অ্যান্টিগ্র্যাভিটি; এবং হার্মিস, কার্সার সিএলআই এবং কিমি তাদের অফিসিয়াল ইনস্টলারের মাধ্যমে প্রথম লঞ্চে। ARGVUS-পরিচালিত বহিরাগত এজেন্ট তালিকা এবং আনইনস্টল করার জন্য [ব্যবহারের নির্দেশিকা](usage/) ব্যবহার করুন।

## Supported agents

The integration supports package-provided OpenCode, Codex and Qwen Code; Claude Code through mise; Antigravity when installed separately; and Hermes, Cursor CLI and Kimi through their official installers on first launch. Use the [usage guide](usage/) for listing and uninstalling ARGVUS-managed external agents.
