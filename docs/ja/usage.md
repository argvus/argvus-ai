## エージェントを開く

**SUPER + A** を押すか、タスクバーのロボットをクリックするか、エージェントのアプリケーションエントリを選択します。セレクタは実行可能な OpenCode/Codex インストールを提供し、mise が存在する場合は初回使用インストール用に Claude Code を提供します。**Esc** を押すと、何も起動せずダウンロードもせずにキャンセルされます。

ターミナルは呼び出し元の作業ディレクトリを引き継ぎます。グラフィカル起動の場合は通常、セッションのホームディレクトリから開始されます。特定の作業ディレクトリが必要な場合は、プロジェクトターミナルからエージェントを起動してください。

## タスクバーの表示

コントロールセンター > 外観 > タスクバー > アイコン > オプションモジュール を開き、AIエージェント を切り替えた後、適用 をクリックします。ロボットは `group/right-2` に属します。引き出しが折りたたまれている場合は、ユーティリティグループを展開してください。プリファレンスは `/taskbar/icons/ai_agents_enabled` で、デフォルトは true で、再生成後も残ります。これはアイコンのみを制御し、ショートカットやデスクトップエントリは引き続き利用可能です。実行時の可用性によっては、有効なアイコンが非表示になることもあります。

## 診断コマンド

```sh
argvus-ai list
argvus-ai status
argvus-ai status --check
argvus-ai menu
argvus-ai launch opencode
argvus-ai launch codex
argvus-ai launch claude
```
`list`はインストール済みエージェントのみを報告します。`status`はWaybarのJSONを出力し、`status --check`は終了ステータスを通じてインストール済みまたはインストール可能なメニュー項目があるかどうかを報告します。Claudeを選択/起動することでのみ、そのインストールを開始できます。`run-claude`は内部端末のエントリーポイントです。

ショートカットがまだ古い組み合わせを使用している場合、コントロールセンターのキーボードショートカットページで個人設定のオーバーライドを確認してください。パッケージ化されたデフォルト設定はこれを上書きしません。外観設定を適用した後にロボットが消える場合は、`argvus-appearance`を更新し、タスクバー設定を再生成/適用してください。生成されたWaybar/Luaファイルを直接編集することは避けてください。

クロードのインストールが失敗した場合は、端末のエラー、ネットワークアクセス、およびインストールされているmiseのバージョンを確認してから、再度クロードを選択してください。miseクエリはホームから実行されるため、プロジェクト固有の設定では異なるツールが選択されません。ラッパーはグラフィカルPATH内でmiseシムを必要としません。OpenCode/Codexの探索は、シェルエイリアスや対話型起動スクリプトなしで、グラフィカルPATHを使用します。

[AI Agents](/docs/argvus-ai/)に戻ります。

エージェントは、ARGVUSヘッダーとフッター付きで、`ARGVUS AI Agent`というタイトルの中央に配置された浮動Kittyウィンドウで開きます。エージェントウィンドウを閉じるには **Ctrl + E** を押します。このショートカットはフレームによって予約されており、EscおよびCtrl+Cは引き続きエージェントで使用可能です。

専用のKittyプロファイル`ai-agents`は、タブを非表示にし、タブ、スプリット、全画面表示の継承されたショートカットをクリアします。クリップボードのショートカットCtrl+Shift+CおよびCtrl+Shift+Vは引き続き使用可能です。その生成された設定はARGVUSキャッシュディレクトリ下の`kitty-tui/kitty-ai-agents.conf`です。パッケージHyprlandモジュールは、クラス`argvus-ai`のウィンドウをフロートさせて中央に配置し、サイズは1399 × 920です。

## エージェントのアンインストール

`argvus-ai list` はインストール済みのエージェントを表示します。`argvus-ai uninstall` を実行し、ARGVUS が管理する Hermes、Cursor CLI、または Kimi を選択して削除を確定します。`argvus-ai uninstall hermes`、`argvus-ai uninstall cursor`、`argvus-ai uninstall kimi` のように個別指定もできます。ARGVUS 以外からのインストールは変更しません。ただし、明示的な Cursor コマンドは `~/.local/bin/agent` が `~/.local/share/cursor-agent/versions/` 内を指す場合に限り、旧 Cursor CLI を認識します。Hermes は公式アンインストーラーを使用します。Cursor と Kimi の実行ファイルを削除し、ユーザー設定、セッション、認証情報は保持します。
