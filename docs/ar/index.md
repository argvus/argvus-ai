`argvus-ai` هو تكامل اختياري لسطح المكتب لـ **OpenCode** و**OpenAI Codex** و**Claude Code**. فهو يوفر محدد Rofi مشتركًا وإدخالات مشغل التطبيقات وأيقونة الروبوت في مجموعة الأدوات المساعدة لشريط المهام. يعمل الوكلاء في نافذة طرفية ARGVUS جديدة ويحتفظون بدليل عمل المتصل.

افتح المحدد باستخدام **SUPER + A** أو انقر فوق **nf-md-robot** في شريط المهام، بجوار الميكروفون وعناصر التحكم في الصوت. يمكنك أيضًا تحديد وكيل فردي في مشغل التطبيقات.

يتم تثبيت OpenCode وCodex كتبعيات للحزمة. يتم تثبيت Claude Code مع Mise، باعتباره المستخدم الخاص بك، فقط عند تحديده لأول مرة. تثبيت الحزمة أو فتح/إلغاء المحدد أو التحقق من الحالة لا يؤدي أبدًا إلى تنزيل Claude. لا تقوم الحزمة بتكوين الحسابات أو مفاتيح API أو الاشتراكات؛ اتبع مطالبات مصادقة الوكيل المحدد.

اقرأ [التثبيت](/docs/argvus-ai/installation/) و[الاستخدام واستكشاف الأخطاء وإصلاحها](/docs/argvus-ai/usage/).

## اللغات

The `ai` المدونات المقدمة في الـ 18 ARGVUS الوصلات البينية والاستخدامات المشتركة `argvus i18n` الإختيار والانفصال الانجليزي تُخزَّن لغة التفاعل المختارة على أنها `ARGVUS_LANGUAGE` في المستعمل `locale.conf`; The system regional locale remains separate. ويتم تركيب الترجمة كبيانات دون كتابة شكل المستخدم.

## تغطية الوكيل

يدعم هذا التكامل OpenCode وCodex وQwen Code المرفقة بالحزمة، وClaude Code عبر mise، وAntigravity عند تثبيته بصورة مستقلة، إضافةً إلى Hermes وCursor CLI وKimi، التي تُثبَّت عبر أدواتها الرسمية عند التشغيل الأول. راجع [دليل الاستخدام](usage/) لمعرفة كيفية عرض الوكلاء الخارجيين الذين يديرهم ARGVUS وإلغاء تثبيتهم.
