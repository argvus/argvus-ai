---
title: AI ایجنٹس
description: ARGVUS ڈیسک ٹاپ سے پروگرامنگ ایجنٹس کھولیں۔
---

`argvus-ai` **OpenCode**، **OpenAI Codex** اور **Claude Code** کے لیے ایک اختیاری ڈیسک ٹاپ انضمام ہے۔ یہ ٹاسک بار یوٹیلیٹی گروپ میں مشترکہ روفی سلیکٹر، ایپلیکیشن لانچر اندراجات اور روبوٹ آئیکن فراہم کرتا ہے۔ ایجنٹ ایک نئی ARGVUS ٹرمینل ونڈو میں چلتے ہیں اور کالر کی ورکنگ ڈائرکٹری کو برقرار رکھتے ہیں۔

سلیکٹر کو **SUPER + A** کے ساتھ کھولیں یا ٹاسک بار میں مائیکروفون اور آڈیو کنٹرولز کے آگے **nf-md-robot** پر کلک کریں۔ آپ ایپلیکیشنز لانچر میں انفرادی ایجنٹ کو بھی منتخب کر سکتے ہیں۔

اوپن کوڈ اور کوڈیکس پیکیج پر انحصار کے طور پر انسٹال کیے گئے ہیں۔ Claude Code کو mise کے ساتھ انسٹال کیا جاتا ہے، بطور صارف، صرف اس وقت جب آپ اسے پہلی بار منتخب کرتے ہیں۔ پیکیج کو انسٹال کرنا، سلیکٹر کو کھولنا/منسوخ کرنا یا اسٹیٹس چیک کرنا کبھی بھی کلاڈ کو ڈاؤن لوڈ نہیں کرتا ہے۔ پیکیج اکاؤنٹس، API کیز یا سبسکرپشنز کو ترتیب نہیں دیتا ہے۔ منتخب ایجنٹ کے تصدیقی اشارے پر عمل کریں۔

پڑھیں [انسٹالیشن](/docs/argvus-ai/installation/) اور [استعمال اور ٹربل شوٹنگ](/docs/argvus-ai/usage/)۔

## زبانیں

`ai` کیٹلاگ تمام دس ARGVUS زبانوں میں فراہم کیا گیا ہے اور مشترکہ `argvus i18n` انتخاب اور انگریزی فال بیک کا استعمال کرتا ہے۔ ترجمہ صارف کنفیگریشن لکھے بغیر ڈیٹا کے طور پر انسٹال کیا جاتا ہے۔

## معاون ایجنٹ

یہ انضمام پیکیج کے ساتھ فراہم کردہ OpenCode، Codex اور Qwen Code، mise کے ذریعے Claude Code، علیحدہ نصب کیے جانے پر Antigravity، اور پہلی بار چلانے پر سرکاری انسٹالرز کے ذریعے نصب ہونے والے Hermes، Cursor CLI اور Kimi کو سپورٹ کرتا ہے۔ ARGVUS کے زیرِ انتظام بیرونی ایجنٹس کی فہرست دیکھنے اور انہیں اَن انسٹال کرنے کے طریقے کے لیے [استعمال گائیڈ](usage/) دیکھیں۔
