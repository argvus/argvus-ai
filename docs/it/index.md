`argvus-ai` è un'integrazione desktop opzionale per **OpenCode**, **OpenAI Codex** e **Claude Code**. Fornisce un selettore condiviso Rofi, voci di avvio delle applicazioni e l'icona del robot nel gruppo delle utilità della barra delle applicazioni. Gli agenti vengono eseguiti in una nuova finestra del terminale ARGVUS e mantengono la directory di lavoro del chiamante.

Apri il selettore con **SUPER + A** o clicca su **nf-md-robot** nella barra delle applicazioni, accanto al microfono e ai controlli audio. Puoi anche selezionare un agente individuale nel launcher delle applicazioni.

OpenCode e Codex sono installati come dipendenze del pacchetto. Claude Code viene installato con mise, come tuo utente, solo quando lo selezioni per la prima volta. Installando il pacchetto, aprendo/annullando il selettore o controllando lo stato non viene mai scaricato Claude. Il pacchetto non configura account, chiavi API o abbonamenti; segui le istruzioni di autenticazione dell'agente selezionato.

Leggi [Installation](/docs/argvus-ai/installation/) e [Usage and troubleshooting](/docs/argvus-ai/usage/).

## Lingue

Il catalogo `ai` è fornito in tutte e dieci le lingue ARGVUS e utilizza la selezione condivisa `argvus i18n` e l'inglese come riserva. Le traduzioni sono installate come dati senza scrivere la configurazione dell'utente.

## Agenti supportati

L’integrazione supporta OpenCode, Codex e Qwen Code inclusi nel pacchetto, Claude Code tramite mise, Antigravity se installato separatamente e Hermes, Cursor CLI e Kimi, installati al primo avvio tramite i rispettivi installer ufficiali. Consulta la [guida all’uso](usage/) per sapere come elencare e disinstallare gli agenti esterni gestiti da ARGVUS.
