## Установите пакет

На Arch Linux с настроенными репозиториями ARGVUS, как только `argvus-ai` будет опубликован там:

```sh
sudo pacman -S argvus-ai
```
Для неопубликованной локальной сборки запустите `make validate` и `make build` в репозитории исходного кода `argvus-ai`, затем установите полученный `.pkg.tar.zst` из `build/dist/` с помощью `sudo pacman -U /path/to/package.pkg.tar.zst`. Pacman должен иметь возможность разрешать свои зависимости, включая основной пакет `argvus`.

Пакет требует `argvus`, `rofi`, `jq`, `mise`, `opencode` и `openai-codex`; Arch предоставляет `/bin/sh` через `bash`. OpenCode работает как `opencode`, а пакет `openai-codex` предоставляет `codex`.

## Интеграция с рабочим столом

Используйте обновленные пакеты `argvus-hyprland` и `argvus-taskbar`. Hyprland загружает необязательный Lua-модуль, предоставляемый `argvus-ai`. Pacman-хук интеграции обновляет стандартную системную конфигурацию после установки или удаления. Пользовательская корневая конфигурация или отключенная автоперезагрузка могут потребовать явной перезагрузки. Существующие пользовательские переопределения ярлыков остаются авторитетными.

Обновлённый проектор `argvus-appearance` сохраняет модуль панели задач и учитывает **Центр управления > Внешний вид > Панель задач > Значки > Дополнительные модули > AI-Агенты**. Опция включена по умолчанию; нажмите **Применить** после изменения. Включение её не устанавливает агентов.

## Claude Code при первом использовании

Выберите Claude Code через селектор Rofi или лаунчер приложений. Откроется терминал ARGVUS и выполнит `mise install claude` от имени вашего обычного пользователя, если установленная версия не найдена. Для первой установки необходим доступ к сети. Обёртка определяет установленный исполняемый файл и добавляет его каталог в PATH запускаемого процесса; она не изменяет файлы запуска оболочки и не устанавливает от имени root. Последующие запуски будут использовать уже установленную версию.

## Удаление

```sh
sudo pacman -R argvus-ai
```
Модуль Lua, принадлежащий пакету, и записи рабочего стола удаляются, а модуль панели задач скрывается, когда его помощник отсутствует. Стандартная конфигурация Hyprland автоматически перезагружается для удаления привязки. Пользовательские инструменты mise, настройки агента и учетные данные сохраняются. Pacman не удаляет автоматически зависимости агента с помощью этой команды.

Пакет AI ARGVUS не устанавливает внешние агенты во время установки пакета. Hermes, Cursor CLI и Kimi устанавливаются при первом запуске; их пользовательские данные остаются вне пакета. Инструкции по удалению см. в руководстве по использованию.
