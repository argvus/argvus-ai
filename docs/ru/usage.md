## Открыть агента

Нажмите **SUPER + A**, кликните по роботу на панели задач или выберите запись приложения агента. Селектор предлагает исполняемые установки OpenCode/Codex и предлагает Claude Code для первой установки, когда имеется mise. **Esc** отменяет без запуска или загрузки чего-либо.

Терминал наследует рабочий каталог вызывающего; графические запуски обычно начинаются из домашнего каталога сессии. Запускайте агента из терминала проекта, когда нужен определённый рабочий каталог.

## Видимость на панели задач

Откройте **Панель управления > Внешний вид > Панель задач > Значки > Дополнительные модули**, переключите **AI Agents**, затем нажмите **Применить**. Робот принадлежит `group/right-2`; если его ящик свернут, разверните группу утилит. Настройка — `/taskbar/icons/ai_agents_enabled`, по умолчанию true, сохраняется после регенерации. Она управляет только значком: ярлыки и элементы рабочего стола остаются доступными. Время выполнения всё ещё может скрывать включённый значок.

## Диагностические команды

```sh
argvus-ai list
argvus-ai status
argvus-ai status --check
argvus-ai menu
argvus-ai launch opencode
argvus-ai launch codex
argvus-ai launch claude
```
`list` сообщает только об установленных агентах. `status` выводит JSON для Waybar, а `status --check` сообщает, есть ли установленный или доступный для установки меню через свой код выхода. Только выбор/запуск Claude может начать его установку; `run-claude` является внутренней точкой входа терминала.

Если ярлык всё ещё использует старую комбинацию, проверьте его персональное переопределение на странице ярлыков клавиатуры в Центре управления; упакованные значения по умолчанию его не перезапишут. Если робот исчезает после применения настроек внешнего вида, обновите `argvus-appearance` и заново создайте/примените настройки панели задач. Избегайте прямого редактирования сгенерированных файлов Waybar/Lua.

Если установка Claude не удается, проверьте ошибки в терминале, доступ к сети и установленную версию mise, затем снова выберите Claude. Запросы mise выполняются из домашнего каталога, поэтому настройка проекта не выбирает другой инструмент. Оболочка не требует mise-шимов в графическом PATH. Обнаружение OpenCode/Codex использует графический PATH, без алиасов оболочки или интерактивных скриптов запуска.

Вернуться к [AI Agents](/docs/argvus-ai/).

Агенты открываются в центрированном плавающем окне Kitty с заголовком `ARGVUS AI Agent` и шапкой и подвалом ARGVUS. Нажмите **Ctrl + E**, чтобы закрыть окно агента. Это сочетание клавиш зарезервировано фреймом; Esc и Ctrl+C остаются доступными агенту.

Специальный профиль Kitty `ai-agents` скрывает вкладки и очищает унаследованные сочетания клавиш для вкладок, разбиений и полноэкранного режима. Сочетания клавиш буфера обмена Ctrl+Shift+C и Ctrl+Shift+V остаются доступными. Его сгенерированная конфигурация находится как `kitty-tui/kitty-ai-agents.conf` в каталоге кэша ARGVUS. Модуль пакета Hyprland плавает и центрирует окна с классом `argvus-ai` размером 1399 × 920.

## Uninstalling agents

`argvus-ai list` shows installed agents. Run `argvus-ai uninstall` to select an ARGVUS-managed Hermes, Cursor CLI, or Kimi installation, then confirm removal. You can also run `argvus-ai uninstall hermes`, `argvus-ai uninstall cursor`, or `argvus-ai uninstall kimi`. Installations made outside ARGVUS are left untouched, except a legacy Cursor CLI install is recognized by the explicit Cursor command when `~/.local/bin/agent` resolves inside `~/.local/share/cursor-agent/versions/`. Hermes uses its official uninstaller. Cursor and Kimi binaries are removed while user settings, sessions, and credentials are preserved.
